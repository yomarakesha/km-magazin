# POS / Касса продавца — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Экран-касса для продавца: скан штрихкода, немедленное списание со склада, ввод реальной суммы (скидка/долг), печать чека A4, учёт долгов; продажи в отчётах и складском журнале.

**Architecture:** Отдельные сущности `Sale`/`SaleItem` (не Order), пишут в общий `StockMovement`-леджер через `log_movement`. Роутер `admin_pos.py` (роль sales, void owner-only) с атомарным guarded-списанием как в create_order. Frontend: страница кассы, история/долги, печатный чек A4.

**Tech Stack:** FastAPI + SQLAlchemy 2.0 (Mapped/mapped_column) + SQLite, Pydantic v2, Next.js 16 + React 19.

## Global Constraints

- Next.js v16 — читать `node_modules/next/dist/docs/` перед фронт-кодом (AGENTS.md).
- Auth fails closed; секреты константным сравнением; REVALIDATE_SECRET не логировать.
- Тесты: общая тестовая БД → дельта-ассерты, не абсолютные суммы.
- Запуск pytest: `$env:ADMIN_PASSWORD="test"; $env:SECRET_KEY="test"; .\.venv\Scripts\python.exe -m pytest`.
- Роли: owner проходит всё; `require_role("sales")` на кассу; `require_role()` (owner) на void.
- Списание: только tracked (`stock_qty IS NOT NULL`); guarded `UPDATE … WHERE stock_qty >= qty`; нехватка → 409.
- Коммит только по явной команде пользователя (шаги «Commit» держать наготове, но не выполнять без разрешения).

```python
class SaleItemIn(BaseModel):
    product_id: int
    qty: int = Field(ge=1)

class SaleIn(BaseModel):
    items: list[SaleItemIn] = Field(min_length=1)
    sold_total: int | None = Field(default=None, ge=0)
    payment_method: Literal["cash", "terminal", "debt"] = "cash"
    debtor_name: str | None = None
    debtor_phone: str | None = None

    @model_validator(mode="after")
    def _debt_needs_debtor(self):
        if self.payment_method == "debt" and not (
            (self.debtor_name or "").strip() and (self.debtor_phone or "").strip()
        ):
            raise ValueError("debtor_name and debtor_phone required for debt")
        return self
```
